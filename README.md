# Andrey AI Lab

Личный сайт фрилансера, который создаёт ИИ-ассистентов и чат-ботов для бизнеса.

Сайт построен на **Flask**, использует **Jinja2**-шаблоны, **SQLAlchemy** + SQLite, **Flask-Login** для админ-панели и **Flask-WTF** с CSRF-защитой для форм.

Дизайн выполнен в минималистичном стиле «Oblivion»: светлый фон, тёмный текст, много воздуха, моноширинные номера секций, белые скруглённые карточки и тонкие разделительные линии.

## Установка и запуск

### 1. Создайте виртуальное окружение (рекомендуется)

```bash
python -m venv venv
```

Активируйте окружение:

- **Windows:**
  ```bash
  venv\Scripts\activate
  ```
- **macOS/Linux:**
  ```bash
  source venv/bin/activate
  ```

### 2. Установите зависимости

```bash
pip install -r requirements.txt
```

### 3. Запустите приложение

```bash
python app.py
```

Сайт будет доступен по адресу: **http://127.0.0.1:5000/**

При первом запуске автоматически создаются:
- база данных `instance/site.db`,
- таблицы,
- учётная запись администратора (логин/пароль берутся из `config.py`).

## Админ-панель

URL: **http://127.0.0.1:5000/admin/**

Данные для входа по умолчанию:
- **Логин:** `admin`
- **Пароль:** `andrey-ai-lab-2025`

> В production обязательно измените логин и пароль в `config.py` или задайте их через переменные окружения `ADMIN_USERNAME` и `ADMIN_PASSWORD`.

В админ-панели можно:
- просматривать заявки из формы обратной связи,
- отмечать заявки как прочитанные / непрочитанные,
- удалять заявки.

## Конфигурация

Все настройки находятся в файле `config.py`:

| Параметр | Описание |
|----------|----------|
| `SECRET_KEY` | Секретный ключ Flask (измените в production) |
| `SQLALCHEMY_DATABASE_URI` | Путь к SQLite-базе |
| `TELEGRAM_URL` | Ссылка на Telegram для кнопки «Обсудить задачу» |
| `ADMIN_USERNAME` | Логин администратора |
| `ADMIN_PASSWORD` | Пароль администратора |
| `LOG_LEVEL` | Уровень логирования |
| `LOG_FILE` | Путь к файлу логов |

## Возможности сайта

- **Главная страница** с hero-блоком, пользой для бизнеса, кейсами и этапами работы.
- **Страница кейсов** и отдельные страницы для каждого кейса.
- **Страница «Обо мне»**.
- **Форма обратной связи** с валидацией всех полей и CSRF-защитой.
- **Адаптивная вёрстка** — корректно отображается на десктопе, планшете и смартфоне.
- **Логирование** запросов страниц и отправки форм в `logs/app.log`.
